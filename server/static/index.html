Agent Passport

Una patente verificabile e revocabile per agenti AI. Un umano firma con la passkey → l'agente porta il mandato → un endpoint lo accetta solo se vivo → premi revoca e si spegne.

1 Crea il tuo passaporto (passkey)

Registri una passkey nel tuo dispositivo: è la radice umana. Nessuna password, nessun server vede la chiave privata.

2 Genera un mandato per un agente

Definisci chi (l'agente), cosa (scope) e per quanto (scadenza). Firmi il mandato con la passkey.

3 L'agente esegue un'azione

L'agente presenta il mandato all'endpoint protetto /agent/act. Il verifier controlla firma + scadenza + revoca + scope.

4 Il contenuto porta una ricevuta firmata (Pilastro 2)

Quando l'agente agisce, produce un output con una ricevuta allegata: lega l'hash del contenuto al mandato. Chiunque può verificarla — anche dopo.

5 Revoca in tempo reale

Spegni il mandato. Poi ri-verifica il contenuto allo step 4: la ricevuta passa da VALIDO a REVOCATO all'istante — senza ri-firmare nulla.
